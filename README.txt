PROFESSIONAL PORTFOLIO WEBSITE

FILES
- index.html: page content
- style.css: responsive visual design
- script.js: mobile navigation and current year

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view it in a browser.

BEFORE PUBLISHING
- Replace "Your Name" with the exact public name you want to use.
- Add your professional email, preferred phone number, LinkedIn and GitHub links in the Contact section.
- Add a professional photograph if desired.
- Review all dates and project descriptions for accuracy.
- Keep project status labels accurate; do not describe work in progress as completed.

The website uses Google Fonts when internet access is available. It still works without them using fallback fonts.
