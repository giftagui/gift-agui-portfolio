# Endurance Gift Agui — Professional Portfolio

Responsive portfolio website featuring professional experience, education, skills, a circular profile portrait and visual project cards.

## Files
- `index.html` — page content
- `style.css` — responsive design
- `script.js` — mobile navigation and current-year footer
- `portrait.png` — profile portrait
- `project-images/` — illustrative project preview graphics

## IMPORTANT: Set your real links before sharing
Search `index.html` for `YOUR-GITHUB-USERNAME` and replace it with your GitHub username. Replace each sample repository URL with the real repository URL once the project is uploaded.

The Live Version buttons currently show a coming-soon/contact state because no deployed project URLs have been supplied. Do not present an undeployed project as a live app.

The project preview graphics are illustrative mockups, not screenshots of completed deployed software. Replace them with actual screenshots as the applications become available.

## Publish with GitHub Pages
1. Create a public repository named `gift-agui-portfolio`.
2. Upload the contents of this folder to the repository root (not the ZIP file).
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the website.

Add your real email, phone number and LinkedIn URL before making the portfolio public.
